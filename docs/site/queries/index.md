# Query reference

Every `query.` name the game knows, with a page each. Which names an expression can use depends on where it is written: entity, block and particle fields use the default set, item and block tag expressions the tag set, and world generation the world generation set.

Each entry shows where its value is meaningful (client, server or both), whether it is deprecated or limited to some Molang versions, and how far its page has been verified in game.
